## 任务要求

1. 先划三条线（范围边界 / 任务类型 / 详略分配表），放在正文开头交代。
2. 先给体系骨架（ASCII 图，代码块），再逐块论证；板块之间是推导关系，
   每块开头交代上一块遗留的问题。
3. 视频里的每个核心定义给全四要素：精确定义 / 存在理由 / 边界（含反例）/
   易混对象；定义要先逼出来再给，不许直接扔定义。
4. 篇幅按重要性分配：核心定义、关键推导、易混点、常见坑展开到底；
   铺垫过渡一两句带过。禁止「标题+一句话」充版面，禁止靠列表符号和空行
   制造长度感。
5. 讲完主动自问自答 3 到 5 个（凭什么 / 怎么想到的 / 换成别的呢 /
   会错在哪 / 和谁像）。
6. 动手类内容结尾给「可复现收口」：复现目标 / 最小复现路径（编号步骤，
   含命令与预期中间结果）/ 预期最终结果 / 失败对照。纯概念视频可省，
   但说明为什么免。
7. 去 AI 味：禁连接词堆砌、禁元叙事、禁学术腔、禁高频「不是…而是…」、
   禁「让/令/使」字句。
8. 引用视频内时间点时用 `mm:ss` 格式，可附 `?t=秒数` 链接。
